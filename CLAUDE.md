# Сайт семейного психолога Екатерины Халиковой

Владелец проекта управляет им в том числе с телефона, через облачные сессии Claude Code. Отвечай по-русски, простыми словами, без технического жаргона.

## Что где лежит
- `site/` — сам сайт: Astro 7 + React 19 + Tailwind 4 + motion. Подробности в `site/README.md`.
- `site/src/lib/site.ts` — контакты, ссылка на MAX, цены, расписание записи.
- `site/src/i18n/ru.ts` и `tt.ts` — все тексты на русском и татарском (татарский нужно вычитать носителем языка).
- `site/src/content/blog/` — статьи блога в Markdown.
- `site/public/api/lead.php` — приём заявок: отправка в Telegram и копия на вебхук для будущего ИИ-агента.
- `analiz-saitov-psihologov.md` — разбор сайтов конкурентов, `scenariy-video.md` — текст видео знакомства.

## Команды (из папки site)
- `npm ci` — установить зависимости.
- `npm run dev` — сайт на http://localhost:4321.
- `npm run build` — собрать в `site/dist/`. Перед сохранением правок всегда проверяй, что сборка проходит.

## Выкладка
Каждое сохранение в ветку `main` запускает `.github/workflows/deploy.yml`: сайт собирается и, если заданы секреты, выкладывается на Beget по FTP. Значит, правка в `main` сразу уходит на живой сайт: крупные изменения сначала показывай владельцу.

## Безопасность
- Никогда не сохраняй в репозиторий пароли, токены и `site/public/api/config.php`.
- Папка `Diplom/` с исходными фото диплома (там видны номера документов) в репозиторий не попадает. На сайте только копии с размытыми номерами.

## Правила текста и дизайна
- Тексты от первого лица пишутся без грамматического рода («Я начинаю практику», а не «Я начала»): род по имени не определяем.
- Без дефисов внутри предложений, в заголовках `text-wrap: balance`.
- Шрифт только Manrope, не жирнее bold, без курсива. Размеры шрифта только из шкалы Tailwind (`text-xs` … `text-9xl`), без `text-[13px]`.
- Иконки только Phosphor (`@phosphor-icons/react`).
- Цвета берутся из токенов в `site/src/styles/global.css` (зелёный `sage`, голубой `sky`, тёмно-зелёный `forest`), новые цвета не выдумывать.
- Анимации на кривой `cubic-bezier(0.22,1,0.36,1)`, 500–600 мс, двигаем только transform и opacity. Учитывать `prefers-reduced-motion`.
- Нижняя панель вкладок `MotionTabs.tsx` повторяет механику github.com/rit3zh/expo-motion-tabs, её тайминги не менять без причины.
- Проверяй вёрстку на ширине 375 px: без горизонтальной прокрутки.
