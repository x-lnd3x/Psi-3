# Сайт семейного психолога Екатерины Халиковой

Статический сайт на Astro + React + Tailwind + Motion. Пять разделов (главная, обо мне, услуги, блог, контакты) на русском и татарском, запись с выбором времени, заявки в Telegram.

## Запуск на компьютере

```bash
npm install
npm run dev
```

Сайт откроется на http://localhost:4321. В режиме разработки заявка не отправляется, а сразу показывает экран «Заявка отправлена».

## Что где менять

| Что | Файл |
|---|---|
| Контакты, ссылка на MAX, цены, расписание для записи | `src/lib/site.ts` |
| Все тексты на русском | `src/i18n/ru.ts` |
| Татарские тексты | `src/i18n/tt.ts` (нужна вычитка носителем языка) |
| Статьи блога | `src/content/blog/*.md` (новый файл = новая статья) |
| Фото диплома | `public/diploma/` |
| Политика конфиденциальности | `src/views/Privacy.astro` |
| Цвета и шрифт | `src/styles/global.css` |

Ссылку на MAX вставьте в `src/lib/site.ts` вместо `null`, кнопки станут активными сами.

## Публикация на Beget

1. Соберите сайт: `npm run build`. Готовые файлы появятся в папке `dist/`.
2. В панели Beget создайте сайт и привяжите домен.
3. Загрузите **содержимое** папки `dist/` в папку `public_html` сайта через «Файловый менеджер» Beget или по FTP (FileZilla).
4. Настройте приём заявок:
   - создайте бота в Telegram через @BotFather и скопируйте токен;
   - напишите своему боту любое сообщение, затем узнайте свой chat id через @userinfobot;
   - на хостинге в папке `public_html/api/` скопируйте `config.example.php` в `config.php` и впишите токен и chat id.
5. В панели Beget включите бесплатный SSL сертификат для домена.
6. Замените домен `khalikova-psy.ru` на настоящий в `astro.config.mjs`, `src/lib/site.ts` и `public/robots.txt`, затем пересоберите сайт.

Файл `config.php` закрыт от просмотра через `.htaccess` и не хранится в git.

## Автоматическая выкладка с GitHub

После настройки сайт выкладывается сам при каждом сохранении в ветку `main`, вручную копировать `dist/` не нужно.

1. В панели Beget, в разделе «FTP», создайте отдельный FTP-аккаунт с доступом к папке сайта. Основной пароль от Beget не используйте.
2. На GitHub откройте репозиторий → Settings → Secrets and variables → Actions → New repository secret и добавьте:
   - `FTP_SERVER` — адрес FTP-сервера из панели Beget;
   - `FTP_USERNAME` и `FTP_PASSWORD` — логин и пароль FTP-аккаунта из шага 1;
   - `FTP_DIR` — папка сайта на сервере со слэшем в конце, например `khalikova-psy.ru/public_html/`.
3. Во вкладке Actions запустите «Сборка и выкладка на Beget» кнопкой Run workflow или просто сохраните любую правку.

Пока секреты не заданы, GitHub только проверяет, что сайт собирается. Файл `api/config.php` на сервере при выкладке не трогается.

## Задел на автоматизацию

`public/api/lead.php` умеет дублировать каждую заявку в JSON на любой адрес (`webhook_url` в `config.php`). Туда позже подключается ИИ-агент или n8n: автоответ клиенту, запись в календарь, напоминания.
